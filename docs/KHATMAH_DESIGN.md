# تصميم نظام الختمة - سراج

خطة تصميم نهائية مبنية على بحث تنافسي معمّق (تطبيق "ختمة" 30 مليون
مستخدم، Muslim Pro، Quran.com، وغيرها). الهدف: أفضل تجربة ختمة ممكنة،
تُبنى مرة واحدة بشكل كامل بلا تكرار.

## الفلسفة المحورية
النظام يدور حول **"الوِرد اليومي"** (حصة اليوم)، لا حول "رقم الصفحة".
المستخدم يفكّر: "ما وِردي اليوم؟ هل أنجزته؟ كم بقي؟" - التصميم كله يخدم
هذا الشعور بالإنجاز والاستمرارية (سلسلة لا تُقطع).

## نموذج البيانات: KhatmahPlan

- id: معرّف فريد (timestamp)
- name: اسم الخطة ("ختمة رمضان"، أو مخصص)
- startDate: تاريخ البدء
- totalDays: مدة الخطة بالأيام
- startPage: صفحة البداية (افتراضي 1، يدعم البدء من منتصف)
- endPage: صفحة النهاية (افتراضي 604)
- currentPage: آخر صفحة أنجزها فعلياً في هذه الخطة
- dailyLog: سجل يومي {"2026-07-08": 45} كم صفحة أُنجزت كل يوم
- reminderTime: وقت التذكير اليومي "07:30" (اختياري)
- isActive: نشطة أم مكتملة/متوقفة
- createdAt: تاريخ الإنشاء

تُخزَّن قائمة من هذه الخطط (تدعم ختمات متوازية) في Hive كـ JSON list
تحت مفتاح واحد 'khatmah_plans' (يتبع نمط CacheService الحالي).

## الحسابات المشتقّة (لا تُخزَّن، تُحسب لحظياً)
- إجمالي الصفحات: endPage - startPage + 1
- الوِرد اليومي المطلوب: ceil(إجمالي الصفحات / totalDays)
- الصفحات المنجزة: currentPage - startPage + 1
- نسبة التقدّم: المنجزة / الإجمالي
- اليوم المتوقّع: أيام مضت منذ البداية
- الحالة: على المسار / متقدّم / متأخر
- ورد اليوم المتبقّي: هل أنجز حصة اليوم من dailyLog؟

## الشاشات

### 1. قائمة الختمات (KhatmahListScreen)
بطاقات للختمات النشطة (اسم، شريط تقدّم، حالة اليوم) + زر "ختمة جديدة"
+ الختمات المكتملة في أرشيف منفصل.

### 2. إنشاء ختمة (KhatmahCreateScreen)
الاسم + طريقة التحديد [مدة بالأيام] أو [ورد يومي بالصفحات] يحسب الآخر
+ خيارات جاهزة (رمضان 30، أسبوعية، شهرية) + نطاق + وقت تذكير.

### 3. تفاصيل الختمة (KhatmahDetailScreen)
شريط تقدّم كبير + "وِردك اليوم: صفحات X-Y" + زر "اقرأ الآن" + الحالة
(على المسار/متأخر) + ورد الأمس/اليوم/الغد + مشاركة.

### 4. وضع قراءة الصفحات (PageReaderScreen)
عرض صفحة مصحف (604 حقيقية من quran_uthmani.json) + تنقّل سحب/أزرار
+ عند إتمام صفحة ضمن ختمة: تحديث currentPage + dailyLog + زر تبديل
بين وضع السورة ووضع الصفحات (بجانب زر التجويد).

## التذكيرات
إشعار محلي يومي في reminderTime لكل خطة نشطة:
"وِردك اليوم من [اسم الختمة]: X صفحات" - عبر نظام الإشعارات المحلي
الموجود (flutter_local_notifications).

## الترجمة
كل النصوص عبر AppLocalizations (15 لغة) من اليوم الأول - لا نصوص ثابتة.

## توحيد متابعة القراءة (يُدمج هنا)
مصدر موضع موحّد: النظام يعرف آخر سياق نشط (سورة عادية أو ختمة) ويوجّه
"متابعة القراءة" من الرئيسية/قسم القرآن للمكان الصحيح. التمرير الدقيق
للآية (المؤجَّل سابقاً) يُنفَذ ضمن هذا.

## ترتيب التنفيذ (كل مرحلة تُختبر قبل التالية)
1. نموذج KhatmahPlan + تخزين/استرجاع في CacheService + حسابات مشتقّة
2. شاشة قائمة الختمات + إنشاء ختمة
3. وضع قراءة الصفحات (PageReaderScreen) + زر التبديل
4. ربط: إتمام صفحة يحدّث الختمة + شاشة التفاصيل بالحالة الكاملة
5. التذكيرات اليومية
6. توحيد متابعة القراءة عبر كل نقاط الدخول + التمرير الدقيق
7. المشاركة + تحسينات (متجاوب iPad، أرشيف)
